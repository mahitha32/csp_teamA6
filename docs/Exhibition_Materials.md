# Project Exhibition Materials

## 1. Poster / Banner Content

### Title Section
**Smart Village Governance Platform**
*Digitizing Panchayat Administration for Gadepudi Village*

### Problem
- Manual paper-based complaints.
- Lack of transparency and delayed resolutions.
- No data to track infrastructure health.

### Solution
An integrated ecosystem consisting of:
1. **Citizen Mobile App**: For easy reporting with GPS and Photos.
2. **Worker Mobile App**: For task assignment and proof-of-work.
3. **Admin Dashboard**: For analytics, routing, and governance.

### Key Technologies
- **Frontend**: React.js, Tailwind CSS / Vanilla CSS, Chart.js
- **Mobile**: Flutter, Dart
- **Backend**: Python (Flask), MySQL, Firebase (Auth/Storage)

### Impact
- **80% Faster** resolution times.
- **100% Accountability** via digital trails.
- **Data-Driven** budget allocation for the village.
